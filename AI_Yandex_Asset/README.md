# AI_Yandex - Плагин для Godot 4.6+

**Автор:** LaskinPO  
**Версия:** 1.0.0  
**Совместимость:** Godot Engine 4.6.3+

## 📖 Описание

Плагин для полного управления Godot через Яндекс Алису. Просто напишите промт на русском языке, а AI агент выполнит все необходимые действия в движке.

## ✨ Возможности

- 🔐 Авторизация через Яндекс (логин/пароль)
- 🤖 Интеграция с Яндекс Алисой
- 📡 Автономная работа в фоне
- 🎯 Управление проектом голосом или текстом
- 🚀 Создание сцен, нод, скриптов
- 💾 Сохранение и запуск проекта

## 📦 Установка

### Вариант 1: Ручная установка

1. Скопируйте папку `addons/AI_Yandex` в ваш проект Godot
2. Откройте Godot Editor
3. Перейдите в `Project → Project Settings → Plugins`
4. Найдите "AI Yandex" и нажмите **Enable**
5. Панель появится в правой части редактора

### Вариант 2: Через Asset Library

1. Откройте `AssetLib` в Godot
2. Найдите "AI Yandex"
3. Нажмите **Download** и **Install**
4. Включите плагин в настройках проекта

## 🚀 Запуск Python сервера

Перед использованием плагина необходимо запустить Python сервер:

```bash
cd python_server
pip install -r requirements.txt
python main.py
```

Сервер запустится на `http://127.0.0.1:5000`

## 🎮 Использование

1. **В панели AI_Yandex (справа в редакторе):**
   - Введите логин от Яндекс аккаунта
   - Введите пароль от Яндекс аккаунта
   - Нажмите кнопку **"🔑 Получить токен"**
   - Нажмите кнопку **"📡 Подключиться"**
   - Включите чекбокс **"🔄 Автономная работа"**

2. **Примеры команд:**
   - "Создай новую сцену"
   - "Добавь ноду Player"
   - "Запусти проект"
   - "Останови проект"
   - "Сохрани сцену"
   - "Создай скрипт"

## 📁 Структура файлов

```
addons/AI_Yandex/
├── plugin.cfg              # Конфигурация плагина
├── ai_agent_plugin.gd      # Главный скрипт плагина
├── http_server.gd          # Модуль сервера
├── dock_ui.tscn            # Сцена интерфейса
└── dock_ui.gd              # Скрипт интерфейса

python_server/
├── main.py                 # Flask сервер
└── requirements.txt        # Зависимости Python
```

## 🔧 API Сервера

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/status` | Проверка статуса сервера |
| POST | `/api/auth/yandex` | Получение токена Яндекс |
| POST | `/api/alice/webhook` | Webhook для Алисы |
| POST | `/api/command` | Выполнение команды |

## ⚠️ Важные замечания

- Для работы плагина требуется запущенный Python сервер
- Голосовое управление осуществляется через Яндекс Алису
- Все команды обрабатываются на русском языке
- Плагин совместим только с Godot 4.6+
