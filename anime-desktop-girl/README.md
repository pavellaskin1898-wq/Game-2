# Аниме девушка на рабочем столе

Приложение для рабочего стола с аниме-девочкой, которая будет вашим компаньоном во время работы.

## Особенности

- 🎨 Прозрачный фон без рамок
- ⏰ Отображение текущего времени
- 💬 Мотивирующие сообщения
- 🌅 Приветствия в зависимости от времени суток
- 📍 Окно всегда поверх других окон
- ❌ Кнопка закрытия

## Установка

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (версия 16 или выше)

2. Клонируйте репозиторий или скопируйте файлы проекта

3. Установите зависимости:
```bash
npm install
```

## Запуск

```bash
npm start
```

## Использование

- Приложение появится в правом нижнем углу экрана
- Вы можете перетаскивать окно за верхнюю панель
- Каждые 10 секунд будут появляться случайные мотивирующие сообщения
- Статус меняется в зависимости от времени суток

## Замена изображения

Чтобы заменить изображение аниме-девушки:

1. Подготовьте PNG-изображение с прозрачным фоном (рекомендуемый размер: 300x500 пикселей)
2. Сохраните его как `anime-girl.png` в папке с проектом
3. Перезапустите приложение
