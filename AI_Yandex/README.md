# AI_Yandex - AI агент для управления Godot с Яндекс Алисой

**Автор:** LaskinPO  
**Версия:** 1.0.0  
**Godot версия:** 4.6.3+

## 📋 Описание

Плагин для полного управления движком Godot через текстовые команды с интеграцией Яндекс Алисы. Голосовое управление отключено - только текстовые промты на русском языке.

## 🚀 Быстрый старт

### 1. Установка плагина в Godot

1. Скопируйте папку `godot_plugin` в ваш проект: `res://addons/AI_Yandex/`
2. Откройте Godot и перейдите в `Project Settings` → `Plugins`
3. Найдите "AI_Yandex" и включите его
4. Панель управления появится **справа** в редакторе

### 2. Запуск Python сервера

```bash
cd AI_Yandex/python_server
pip install -r requirements.txt
python main.py
```

Сервер запустится на `http://localhost:5000`

### 3. Настройка в Godot

В панели AI_Yandex (справа):
1. Введите **логин** от Яндекс аккаунта
2. Введите **пароль** от Яндекс аккаунта
3. Нажмите **"🔑 Получить токен"**
4. Нажмите **"📡 Подключиться к серверу"**
5. Включите **"🔄 Автономная работа"** для постоянной связи

## 🎯 Примеры команд

Просто напишите промт на русском:
- "Создай новую сцену"
- "Добавь ноду Node3D"
- "Запусти проект"
- "Сохранить сцену"
- "Создай скрипт для игрока"


## ⚙️ Настройка Яндекс Алисы

Для полноценной интеграции с Алисой:
1. Зарегистрируйте навык в [Яндекс Диалогах](https://dialogs.yandex.ru/)
2. Укажите webhook URL: `http://ваш-ip:5000/api/alice/webhook`
3. Получите Client ID и Secret в OAuth Яндекс
4. Обновите `main.py` с вашими credentials

## 🔒 Безопасность

- Пароли не сохраняются в проекте
- Токен хранится только в памяти сессии
- Для продакшена используйте HTTPS
