# 🤖 AI_Yandex - Плагин для Godot 4.6.3

**Автор:** LaskinPO  
**Версия:** 1.0.0  
**Совместимость:** Godot Engine 4.6.3+

## Описание

Плагин для полного управления движком Godot через интеграцию с Яндекс Алисой. Позволяет управлять проектом, создавать сцены, ноды и скрипты с помощью текстовых команд на русском языке.

## Структура установки

```
addons/AI_Yandex/
├── plugin.cfg              # Конфигурация плагина
├── ai_agent_plugin.gd      # Главный скрипт EditorPlugin
├── http_server.gd          # Модуль сервера
├── dock_ui.tscn            # Сцена интерфейса
└── dock_ui.gd              # Скрипт интерфейса
```

## Быстрый старт

### 1. Установка в Godot

1. Скопируйте папку `addons/AI_Yandex` в корень вашего проекта Godot
2. Откройте Godot Editor
3. Перейдите в `Project → Project Settings → Plugins`
4. Найдите "AI Yandex" и нажмите **Enable**
5. Панель появится в **правой части редактора**

### 2. Запуск Python сервера

```bash
cd python_server
pip install -r requirements.txt
python main.py
```

Сервер запустится на `http://127.0.0.1:5000`

### 3. Настройка в Godot

В панели AI_Yandex (справа):

1. Введите **Логин Яндекс**
2. Введите **Пароль Яндекс**
3. Нажмите **🔑 Получить токен**
4. Нажмите **📡 Подключиться к серверу**
5. Включите **🔄 Автономная работа** (опционально)

## Возможности

### Текстовые команды (на русском):

- **"Создай новую сцену"** - создание новой сцены
- **"Добавь ноду Player"** - добавление ноды
- **"Запусти проект"** - запуск проекта (F5)
- **"Останови проект"** - остановка проекта
- **"Сохрани сцену"** - сохранение текущей сцены
- **"Создай скрипт"** - создание нового GDScript

## API Сервера

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/status` | GET | Проверка статуса сервера |
| `/api/auth/yandex` | POST | Получение OAuth токена |
| `/api/command` | POST | Выполнение команды |

### Пример запроса:

```bash
curl -X POST http://127.0.0.1:5000/api/command \
  -H "Content-Type: application/json" \
  -d '{"command": "Создай новую сцену"}'
```
