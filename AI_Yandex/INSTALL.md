# 📥 Инструкция по установке AI_Yandex

## Шаг 1: Подготовка Python сервера

```bash
cd /workspace/AI_Yandex/python_server
pip install -r requirements.txt
```

## Шаг 2: Запуск сервера

```bash
python main.py
```

Сервер должен ответить: `✅ Сервер запущен на http://localhost:5000`

## Шаг 3: Установка плагина в Godot

1. Откройте Godot Engine 4.x
2. Создайте новый проект или откройте существующий
3. Скопируйте папку `addons/AI_Yandex` из `/workspace/AI_Yandex/` в корень вашего проекта
4. Перезапустите Godot (если проект был открыт)

## Шаг 4: Включение плагина

1. В Godot перейдите: **Project → Project Settings → Plugins**
2. Найдите **AI_Yandex** в списке
3. Поставьте галочку **Enable**
4. Панель AI_Yandex появится **справа** в редакторе

## Шаг 5: Настройка подключения к Алисе

В панели AI_Yandex (справа):

1. ✅ Убедитесь, что Python сервер запущен
2. 🔗 Нажмите **📡 Подключиться** - должен появиться статус "✅ Подключено"
3. 🔐 Введите **Логин Яндекс** (ваш логин от Яндекс)
4. 🔑 Введите **Пароль Яндекс** (ваш пароль)
5. 🎫 Нажмите **🔑 Получить токен** - токен будет получен автоматически
6. 🔄 Включите **🔄 Автономная работа**

## Шаг 6: Проверка работы

Скажите Алисе одну из команд:
- "Алиса, создай новую сцену"
- "Алиса, добавь игрока"
- "Алиса, запусти проект"

Если всё работает - вы увидите выполнение команды в Godot!

## ❗ Возможные проблемы

### "Сервер недоступен"
- Проверьте, что Python сервер запущен
- Попробуйте открыть в браузере: http://localhost:5000/api/status

### "Ошибка получения токена"
- Проверьте правильность логина/пароля
- Убедитесь, что аккаунт Яндекс активен
- Попробуйте сбросить пароль и получить новый

### Панель не видна
- Нажмите кнопку **🤖 AI_Yandex** в верхней панели Godot
- Или перезапустите Godot
