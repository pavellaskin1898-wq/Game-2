# 🤖 AI_Yandex - Полное управление Godot через Яндекс Алису

**Автор:** LaskinPO  
**Версия:** 1.0.0  
**Godot версия:** 4.x

## 📦 Описание

AI_Yandex - это плагин для Godot Engine, который позволяет управлять движком с помощью голосовых команд через Яндекс Алису. Просто скажите Алисе, что нужно сделать, и она выполнит команду в редакторе Godot.

## ✨ Возможности

- 🎙️ **Голосовое управление** через Яндекс Алису
- 🔐 **Простая аутентификация** - введите логин и пароль от Яндекс
- 🔄 **Автономная работа** - постоянная связь с Алисой
- 📊 **Удобный интерфейс** - панель управления справа в редакторе
- 🚀 **Создание сцен и нод** автоматически
- 💻 **Работа со скриптами** GDScript

## 🚀 Быстрый старт

### 1. Установка Python сервера

```bash
cd /workspace/AI_Yandex/python_server
pip install -r requirements.txt
python main.py
```

Сервер запустится на `http://localhost:5000`

### 2. Подключение плагина в Godot

1. Откройте ваш проект в Godot 4.x
2. Скопируйте папку `addons/AI_Yandex` в ваш проект
3. Включите плагин: **Project Settings → Plugins → AI_Yandex → Enable**
4. Панель AI_Yandex появится **справа** в редакторе

### 3. Настройка подключения

В панели AI_Yandex (справа):

1. **URL сервера:** `http://localhost:5000` (по умолчанию)
2. **Логин Яндекс:** введите ваш логин от Яндекс
3. **Пароль Яндекс:** введите ваш пароль
4. Нажмите **🔑 Получить токен** - токен будет получен автоматически
5. Нажмите **📡 Подключиться** - проверка связи с сервером
6. Включите **🔄 Автономная работа** для постоянной связи

## 🎯 Примеры команд Алисе

Говорите Алисе следующие команды:

- **"Создай новую сцену"** - создаст новую сцену
- **"Добавь игрока"** - добавит ноду игрока
- **"Запусти проект"** - запустит проект на выполнение
- **"Сохрани сцену"** - сохранит текущую сцену
- **"Создай скрипт"** - создаст новый GDScript скрипт

## ⚙️ API Сервера

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/auth/yandex` | Получение OAuth токена по логину/паролю |
| GET | `/api/status` | Проверка статуса сервера |
| POST | `/api/alice/webhook` | Webhook для Яндекс Диалогов |
| POST | `/api/command` | Выполнение команды в Godot |

## 🛠️ Решение проблем

### Ошибка подключения к серверу
- Убедитесь, что Python сервер запущен
- Проверьте URL сервера в настройках плагина
- Проверьте фаервол (порт 5000)

### Не получается получить токен
- Проверьте правильность логина и пароля
- Убедитесь, что у аккаунта Яндекс включены API
- Попробуйте получить токен вручную через Яндекс OAuth

### Панель не отображается
- Нажмите кнопку **🤖 AI_Yandex** в тулбаре
- Перезапустите Godot
- Проверьте, что плагин включен в Project Settings
