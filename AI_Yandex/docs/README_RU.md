# AI_Yandex - Полное управление Godot через Яндекс Алису

**Автор:** LaskinPO  
**Версия:** 1.0.0

## 📖 Описание

AI_Yandex - это плагин для Godot 4.x, который позволяет полностью управлять движком через голосовые команды Яндекс Алисы. Просто скажите команду на русском языке, и AI агент выполнит необходимые действия в редакторе Godot.

## ✨ Возможности

- 🎙️ **Голосовое управление** через Яндекс Алису
- 🤖 **AI процессор** с распознаванием русского языка
- 📝 **Создание сцен, нод и скриптов** по команде
- ▶️ **Запуск проекта** голосом
- 💾 **Автосохранение** сцен
- 🔐 **Удобная аутентификация** через логин/пароль Яндекс
- 🖥️ **Панель управления справа** в редакторе Godot

## 🚀 Быстрый старт

### 1. Установка плагина в Godot

1. Скопируйте папку `godot_plugin` в ваш проект Godot (в папку `addons/`)
2. Откройте Godot и перейдите в `Проект → Настройки → Плагины`
3. Найдите "AI_Yandex" и включите его
4. Панель управления появится в правой части редактора

### 2. Запуск Python сервера

```bash
cd AI_Yandex/python_server
pip install -r requirements.txt
python main.py
```

Сервер запустится на `http://localhost:5000`

### 3. Настройка Яндекс Алисы

#### Получение OAuth токена:

1. Зарегистрируйте приложение в [Яндекс OAuth](https://oauth.yandex.ru/client/new)
2. Получите `Client ID` и `Client Secret`
3. Откройте файл `python_server/main.py` и замените:
   ```python
   CLIENT_ID = 'your_yandex_client_id'
   CLIENT_SECRET = 'your_yandex_client_secret'
   ```

#### В панели плагина Godot:

1. Введите ваш **логин Яндекс**
2. Введите ваш **пароль Яндекс**
3. Нажмите **"🔑 Получить токен"**
4. Нажмите **"📡 Подключиться"**
5. Включите **"🔄 Автономная работа"**

### 4. Настройка навыка Алисы

1. Перейдите в [Яндекс Диалоги](https://dialogs.yandex.ru/)
2. Создайте новый навык
3. Укажите Webhook URL: `https://your-server.com/api/alice/webhook`
   - Для локальной разработки используйте ngrok: `ngrok http 5000`
4. Опубликуйте навык

## 🎯 Примеры команд

Скажите Алисе:

- **"Создай новую сцену"** → Создаст новую сцену с Node3D
- **"Добавь игрока"** → Добавит ноду CharacterBody3D
- **"Запусти проект"** → Запустит проект на тестирование
- **"Сохранить сцену"** → Сохранит текущую сцену
- **"Создай скрипт"** → Создаст новый GDScript

## ⚙️ Настройки

Все настройки сохраняются в `user://ai_yandex_settings.cfg`:

- `server_url` - URL Python сервера (по умолчанию: http://localhost:5000)
- `yandex_login` - Логин от Яндекс аккаунта
- `yandex_password` - Пароль от Яндекс аккаунта
- `yandex_token` - OAuth токен (получается автоматически)
- `auto_work` - Режим автономной работы

## 🛠️ Расширение функционала

Для добавления новых команд:

1. Откройте `godot_plugin/ai_agent_plugin.gd`
2. Добавьте новую команду в метод `execute_command()`
3. Реализуйте логику в новом методе `_your_command()`

Пример:
```gdscript
func execute_command(command: String, parameters: Dictionary = {}) -> void:
    match command:
        "your_command":
            _your_command(parameters)

func _your_command(params: Dictionary) -> void:
    # Ваша логика здесь
    print("Выполняется ваша команда")
```

## ⚠️ Важные замечания

1. **Безопасность:** Не храните пароли в открытом виде в продакшене
2. **OAuth:** Для продакшена используйте полноценный OAuth 2.0 flow
3. **Сеть:** Для удаленного доступа настройте HTTPS и firewall
4. **Тестирование:** Всегда тестируйте команды перед использованием в реальном проекте
