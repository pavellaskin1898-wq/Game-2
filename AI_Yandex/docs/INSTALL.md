# 🚀 Установка AI_Yandex - Полная инструкция

**Автор:** LaskinPO  
**Версия:** 1.0.0

## 📋 Что вы получите

После установки вы сможете управлять Godot голосом через Яндекс Алису:
- Говорите команды на русском языке
- Алиса передаёт команды серверу
- Сервер обрабатывает и выполняет в Godot
- Панель управления справа в редакторе

---

## 🔧 Шаг 1: Подготовка

### Требования:
- ✅ Godot 4.0+
- ✅ Python 3.8+
- ✅ Аккаунт Яндекс

---

## 🔧 Шаг 2: Регистрация приложения в Яндекс OAuth

1. Перейдите на https://oauth.yandex.ru/client/new
2. Заполните форму:
   - **Название:** AI_Yandex Godot Plugin
   - **Платформа:** Веб-сервисы
   - **Redirect URI:** http://localhost:5000/callback
3. Нажмите "Создать приложение"
4. Скопируйте:
   - **Client ID** (например: `abc123xyz...`)
   - **Client Secret** (нажмите "Показать")

---

## 🔧 Шаг 3: Настройка Python сервера

### 3.1 Откройте файл настройки

```bash
cd /путь/к/AI_Yandex/python_server
nano main.py
```

### 3.2 Найдите и замените (строки ~50-51):

```python
CLIENT_ID = 'your_yandex_client_id'  # Вставьте ваш Client ID
CLIENT_SECRET = 'your_yandex_client_secret'  # Вставьте ваш Client Secret
```

### 3.3 Сохраните и установите зависимости:

```bash
pip install -r requirements.txt
```

---

## 🔧 Шаг 4: Установка плагина в Godot

### 4.1 Скопируйте плагин:

```bash
# В папку вашего проекта Godot
cp -r /путь/к/AI_Yandex/godot_plugin /путь/к/вашему/проекту/addons/AI_Yandex
```

Или просто перетащите папку `godot_plugin` в проводнике.

### 4.2 Активируйте плагин:

1. Откройте проект в Godot
2. Меню: **Проект → Настройки → Плагины**
3. Найдите **"AI_Yandex"** в списке
4. Поставьте галочку ✅
5. Панель появится **справа** в редакторе

---

## 🔧 Шаг 5: Первая настройка в Godot

В панели AI_Yandex (справа):

1. **URL сервера:** оставьте `http://localhost:5000`
2. **Логин Яндекс:** введите ваш логин от Яндекс
3. **Пароль Яндекс:** введите ваш пароль
4. Нажмите **"🔑 Получить токен"**
   - Если всё верно → увидите "✅ Токен получен!"
5. Нажмите **"📡 Подключиться"**
   - Должно стать "✅ Подключено к серверу"
6. Включите **"🔄 Автономная работа"**

---

## 🔧 Шаг 6: Запуск сервера

```bash
cd /путь/к/AI_Yandex/python_server
python main.py
```

Вы увидите:
```
🚀 Запуск AI Agent сервера для Godot...
📡 Webhook URL для Яндекс Алисы: http://localhost:5000/api/alice/webhook
🎮 Godot контроллер инициализирован
 * Running on http://0.0.0.0:5000
```

**Оставьте терминал открытым!**

---

## 🔧 Шаг 7: Настройка навыка Алисы

### 7.1 Создайте навык:

1. Перейдите на https://dialogs.yandex.ru/
2. Нажмите **"Создать диалог"**
3. Выберите **"Skill in Yandex Dialogs"**

### 7.2 Настройте webhook:

#### Для локального тестирования:

1. Установите ngrok: https://ngrok.com/
2. Запустите: `ngrok http 5000`
3. Скопируйте URL (например: `https://abc123.ngrok.io`)
4. В настройках навыка укажите:
   - **Webhook URL:** `https://abc123.ngrok.io/api/alice/webhook`

#### Для продакшена:

- Используйте ваш сервер с белым IP
- URL: `https://your-domain.com/api/alice/webhook`

### 7.3 Опубликуйте навык:

1. Заполните название и описание
2. Нажмите **"Опубликовать"**
3. Пройдите модерацию (1-2 дня)

## ⚠️ Возможные проблемы

### ❌ "Ошибка получения токена"

**Решение:**
- Проверьте правильность Client ID и Client Secret
- Убедитесь, что приложение создано в Яндекс OAuth
- Проверьте логин/пароль от Яндекс аккаунта

### ❌ "Сервер недоступен"

**Решение:**
- Убедитесь, что `python main.py` запущен
- Проверьте порт 5000: `netstat -an | grep 5000`
- Отключите firewall на время теста

### ❌ "Плагин не появляется в Godot"

**Решение:**
- Папка должна называться `addons/AI_Yandex`
- В `plugin.cfg` должно быть `name="AI_Yandex"`
- Перезапустите Godot

### ❌ "Алиса не отвечает"

**Решение:**
- Проверьте, что навык опубликован
- Убедитесь, что webhook URL доступен из интернета
- Проверьте логи навыка в Яндекс Диалогах

## 🔐 Безопасность
