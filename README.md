# AI_Yandex - AI Агент для Godot с Яндекс Алисой

**Автор:** LaskinPO  
**Версия:** 1.0  
**Godot:** 4.6.3+

## Описание

Плагин для полного управления движком Godot через текстовые команды на русском языке с интеграцией Яндекс Алисы.

## Структура проекта

```
/workspace/
├── addons/AI_Yandex/          # Плагин для Godot
│   ├── plugin.cfg             # Конфигурация плагина
│   ├── ai_agent_plugin.gd     # Основной скрипт плагина
│   ├── http_server.gd         # TCP сервер для связи
│   ├── dock_ui.tscn           # Сцена интерфейса
│   └── dock_ui.gd             # Скрипт интерфейса
├── python_server/             # Python сервер
│   ├── main.py                # Flask сервер
│   └── requirements.txt       # Зависимости
└── README.md                  # Этот файл
```

## Установка

### 1. Настройка плагина в Godot

1. Скопируйте папку `addons/AI_Yandex` в ваш проект Godot
2. Откройте проект в Godot 4.6.3+
3. Перейдите в `Project Settings → Plugins`
4. Включите плагин **AI_Yandex**
5. Панель появится в правой части редактора

### 2. Запуск Python сервера

```bash
cd /workspace/python_server
pip install -r requirements.txt
python main.py
```

Сервер запустится на `http://127.0.0.1:5000`

## Использование

### В панели AI_Yandex (справа в Godot):

1. **Введите логин Яндекс** в поле "Yandex Login"
2. **Введите пароль Яндекс** в поле "Yandex Password"
3. Нажмите **"🔑 Get Token"** для получения токена
4. Нажмите **"📡 Connect to Server"** для подключения
5. Включите **"🔄 Autonomous Mode"** для автономной работы
6. Вводите команды на русском в текстовом поле и нажмите **"▶ Send Command"**

### Примеры команд:

- "Создай новую сцену"
- "Добавь ноду Player"
- "Запусти проект"
- "Останови проект"
- "Сохрани сцену"
- "Создай скрипт"

## API Сервера

### GET /api/status
Проверка статуса сервера

### POST /api/auth/yandex
Получение токена Яндекс
```json
{
  "login": "ваш_логин",
  "password": "ваш_пароль"
}
```

### POST /api/command
Выполнение команды
```json
{
  "command": "Создай сцену",
  "language": "ru"
}
```

### POST /api/alice/webhook
Webhook для Яндекс Алисы

## Важные замечания

1. **OAuth настройка:** Для полноценной работы с Яндекс Алисой необходимо зарегистрировать приложение в [Яндекс OAuth](https://oauth.yandex.ru/) и получить `client_id` и `client_secret`

2. **Безопасность:** Никогда не храните пароли в открытом виде. В продакшене используйте OAuth flow с redirect

3. **Голосовое управление:** Отключено. Работает только текстовый ввод команд
