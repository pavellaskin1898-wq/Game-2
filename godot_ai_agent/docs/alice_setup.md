# Документация по настройке Яндекс Алисы

## Шаг 1: Регистрация в Yandex Dialogs

1. Перейдите на https://dialogs.yandex.ru/
2. Войдите под своим Яндекс аккаунтом
3. Нажмите "Создать диалог"

## Шаг 2: Создание навыка

### Основные настройки
- **Название**: AI Agent для Godot
- **Описание**: Голосовое управление игровым движком Godot через AI
- **Картинка**: (опционально) загрузите иконку

### Настройка webhook
- Выберите тип навыка: **Webhook**
- URL webhook: `https://your-server.com/api/alice/webhook`
  - Для локальной разработки используйте ngrok или аналогичный сервис

## Шаг 3: Получение OAuth токена

1. В личном кабинете Яндекса перейдите в раздел API
2. Создайте новое OAuth приложение
3. Скопируйте полученный токен
4. Добавьте токен в файл `.env`:
   ```
   YANDEX_OAUTH_TOKEN=ваш_токен
   ```

## Шаг 4: Настройка локального доступа (ngrok)

Для тестирования локально:

```bash
# Установите ngrok
# Запустите сервер
python python_server/main.py

# В другом терминале запустите ngrok
ngrok http 5000
```

Используйте полученный URL от ngrok в настройках навыка Яндекс Диалогов.

## Шаг 5: Тестирование

1. Откройте Яндекс Браузер или приложение с Алисой
2. Скажите: "Запусти навык AI Agent для Godot"
3. Произнесите команду, например:
   - "Создай новую сцену"
   - "Добавь игрока"
   - "Запусти проект"
   - "Сохрани сцену"

## Примеры команд для Алисы

### Базовые команды:
- "Создай сцену"
- "Добавь спрайт"
- "Добавь камеру"
- "Запусти проект"
- "Сохрани"

### Расширенные команды:
- "Создай 2D сцену с игроком"
- "Добавь физический объект"
- "Создай скрипт движения"
- "Добавь UI интерфейс"
- "Настрой коллизию"

## Troubleshooting

### Ошибка подключения
Проверьте:
- Сервер запущен (`python main.py`)
- Webhook URL правильный
- OAuth токен действителен

### Алиса не понимает команды
- Говорите четко
- Используйте поддерживаемые команды из списка
- Проверьте логи сервера
