# AI Agent для Godot с интеграцией Яндекс Алисы

## Описание
Система для полного управления движком Godot через голосовые команды Яндекс Алисы. 
Вы можете говорить команды на русском языке, а ИИ агент будет автоматически выполнять необходимые действия в движке.

## Возможности
- Голосовое управление через Яндекс Алису
- Создание и редактирование сцен
- Добавление и настройка нод
- Управление проектом
- Выполнение скриптов
- Навигация по интерфейсу
- Автоматизация рутинных задач

## Установка

### 1. Установка Python зависимостей
```bash
cd python_server
pip install -r requirements.txt
```

### 2. Настройка Яндекс Алисы
1. Зарегистрируйтесь в [Yandex Dialogs](https://dialogs.yandex.ru/)
2. Создайте новый навык
3. Получите OAuth токен
4. Укажите webhook URL вашего сервера

### 3. Установка плагина в Godot
1. Скопируйте папку `godot_plugin` в ваш проект Godot
2. Включите плагин в Project Settings → Plugins
3. Настройте параметры подключения к серверу

## Запуск

### Запуск Python сервера
```bash
python python_server/main.py
```

### Настройка в Godot
1. Откройте проект в Godot
2. Перейдите в настройки плагина AI Agent
3. Укажите адрес сервера (по умолчанию: http://localhost:5000)
4. Введите ваш Yandex OAuth токен

## Примеры команд

Вы можете говорить Алисе следующие команды:

- "Создай новую сцену с игроком"
- "Добавь спрайт персонажа"
- "Создай скрипт для движения"
- "Запусти проект"
- "Сохрани текущую сцену"
- "Добавь камеру"
- "Настрой физику для объекта"
- "Создай UI интерфейс"

## Требования
- Godot 4.0 или выше
- Python 3.8+
- Аккаунт Яндекс с доступом к API
- Стабильное интернет соединение
